# Text Sentiment Annotation Project

## 1. Project Overview
This is a practical demonstration of text sentiment annotation. The objective is to classify customer feedback based on the sentiment expressed in each statement.

## 2. Annotation Labels

- **POSITIVE:** Expresses satisfaction, happiness or approval.
- **NEGATIVE:** Expresses dissatisfaction, frustration or disappointment.
- **NEUTRAL:** Contains no clear positive or negative opinion.
- **MIXED:** Contains both positive and negative opinions.

## 3. Annotation Guidelines

1. Read the entire customer statement before assigning a label.
2. Identify the overall sentiment and context.
3. Assign only one appropriate label.
4. Avoid making assumptions beyond the text.
5. Review classifications for consistency and accuracy.

## 8. Quality Assurance and Validation

The following checks were applied during the annotation process:

- Reviewed each statement before assigning a label.
- Applied the same classification guidelines consistently.
- Distinguished neutral statements from emotional opinions.
- Identified mixed sentiment where positive and negative opinions appeared together.
- Checked that each assigned label matched the explanation.
- Reviewed ambiguous wording to reduce classification errors.

## 9. Project Limitations

This project uses a small, manually created sample dataset for demonstration and learning purposes. The results should not be interpreted as a benchmark of annotation accuracy on a large real-world dataset.
